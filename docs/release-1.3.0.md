Nova Player 1.3.0 makes subtitle and audio synchronization easier.

- Enter an exact subtitle offset directly, including a four-second correction in one edit.
- Adjust with a slider or ±0.1, ±1, and ±5 second buttons, with clear earlier/later guidance.
- Correct gradual text-subtitle drift with independent subtitle speed from 50% to 200%.
- Reset timing and subtitle speed separately.
- Use the same direct entry, slider, and larger adjustments for audio synchronization.
- Shift+Z / Shift+X adjusts subtitle timing by one second; Z / X retains fine adjustments.
- Timing corrections reset for the next video.
- Improved input focus handling and visible keyboard focus indicators.

Validation: Electron UI interaction tests, bundled mpv IPC property checks, JavaScript syntax checks, and visual layout review.

Windows x64: download the Setup executable to install, or extract the portable ZIP and run Nova Player.exe.
